# HUB75 display-frame user manual

## Inspect the project

After bootstrap, open `dsg/openscad/main.scad` for interactive inspection.
Standard core couplers remain the default full-display assembly. Tube-aware
couplers and detachable clamp/dovetail geometry remain explicit opt-in WIP.

## Build

Use the project tooling rather than invoking ad-hoc repository scripts:

```text
tools/tool.scad-project/scad-project.ps1 build
```

Normal generated output is published under the technical Build/Verification
namespaces. The root README links to the latest generated galleries.

## Current acceptance boundary

The v0.0.4 design checkpoint is digitally qualified. Core panel/coupler physical
fit is still open in issue #43 and depends on the relevant real-panel validation
owned by `lib.scad.hub75`.

Do not treat tube-mount/dovetail renders as physical fit acceptance. The
project plan and [50-00-verification.md](50-00-verification.md) define the
current gates.
